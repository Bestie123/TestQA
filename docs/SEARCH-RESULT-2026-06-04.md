# Итоговый отчёт: Кнопка "Дополнительные доходы" и "Создать прогнозы"

Дата поиска: 2026-06-04

---

## 1. Главный вывод

**Кнопка "Дополнительные доходы" ЕСТЬ в карточке прогноза.** Она не убрана.

Кнопка находится в интерфейсе прогноза и используется для внесения дополнительных доходов/расходов по сотрудникам.

## 3. Кнопка "Дополнительные доходы"

### Где находится
В **карточке прогноза** (не проекта!) — кнопка "Дополнительные доходы".

### Для каких проектов доступна
- **Сервисные проекты** (все типы учёта трудозатрат)
- **Сорсинговые проекты**

### История (из Jira)

| Задача | Описание | Статус |
|---|---|---|
| **IBPA2-1521** | Epic: Единое поле для внесения доп.расходов/доп.доходов | Закрыт |
| **IBPA2-1557** | Реализовать внесение через один источник | Закрыт |
| **IBPA2-1520** | Дефект: Нельзя добавить доп.доходы для "Фикс"/"T&M"/"Фикс+T&M" | Закрыт (исправлено) |
| **IBPA2-2738** | Дефект: Невозможно добавить запись при незаполненных датах | Закрыт (исправлено) |

### Примечание из IBPA2-1520
> "нажать 'Дополнительные доходы' **(если кнопки нет, то назначить текущего пользователя исполнителем)**"

Это означает: кнопка может не отображаться, если пользователь не является исполнителем прогноза.

## 4. Кнопка "Создать прогнозы"

### Где находится
В **карточке проекта** (не прогноза!).

### Поведение

| Тип учёта трудозатрат | Кнопка | Результат |
|---|---|---|
| **"По умолчанию"** | "Создать прогноз" (ед.ч.) | Открывает **модальное окно** с полями: Дата начала, Дата окончания, Прогнозная сумма |
| **"Фикс"** | "Создать прогнозы" (мн.ч.) | Создаёт помесячные прогнозы **автоматически** |
| **"T&M"** | "Создать прогнозы" (мн.ч.) | Создаёт помесячные прогнозы **автоматически** |
| **"Фикс+T&M"** | "Создать прогнозы" (мн.ч.) | Создаёт помесячные прогнозы **автоматически** |

### Источник
- Wiki: https://wiki.ifellow.ru/pages/viewpage.action?pageId=148695899 (обновлено янв 2025)

## 6. Ответ на вопрос

**Да, кнопка "Дополнительные доходы" должна быть.** Она находится в карточке прогноза.

Если кнопки нет — проверьте:
1. Пользователь является исполнителем прогноза
2. Прогноз в статусе "Инициация" (для редактирования)
3. Тип учёта трудозатрат проекта поддерживает доп.доходы (все типы)
