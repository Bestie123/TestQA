### Ключевые находки

1. **numericId ≠ key:** URL `#/testCase/2089` → ключ `IBPA-T2100` (не `IBPA-T2089`)
2. **Jira date format:** `dd/MMM/yy` (русс.месяц), не `dd/MM/yyyy`
3. **React Select в Workflow:** Договор проекта и Акт загружаются через API, но могут быть пусты в тестовом окружении
4. **MailHog:** Работает на `mailhog.ifellow.ru`. Уведомления приходят мгновенно.
5. **Impersonation:** ScriptRunner SwitchUser работает через React Select (click placeholder → type → ArrowDown → Enter → Run)
6. **Workflow «Счет оплачен»:** Требует оба поля: Дата оплаты + Фактическая сумма
